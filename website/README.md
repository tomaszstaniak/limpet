# Limpet website

The static website is published at https://tomaszstaniak.github.io/limpet/.
GitHub Actions deploys only this directory after changes on main.

For a local preview, run `python3 -m http.server 8765 --directory website` from the repository root.

Keep the text in step with the README and `doc/`. When a new version is released, update the version, the three archive URLs and the SDK link. Screenshots keep the system and Limpet version named in their captions; replace a screenshot together with its caption.
